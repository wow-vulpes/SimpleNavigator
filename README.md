# Simple Navigator
## О проекте

Данный проект представляет собой библиотеку для работы с графами, реализованную на Java, а также консольное приложение.
Поддерживается работа с ориентированными и неориентированными взвешенными графами, представленными в виде матрицы смежности.

Также реализован набор классических алгоритмов на графах и консольное приложение для их демонстрации.

Проект выполнен в рамках учебного задания с соблюдением Google Java Style Guide.

## Технологии
- Java 21
- JUnit для unit-тестирования
- Makefile для сборки и автоматизации проекта
- CLI (консольное приложение)
- Google Java Style

## Архитектура проекта

Проект состоит из двух библиотек:

`s21_graph`

Отвечает за хранение и работу с графом.

**Основной класс:**

- `Graph` — хранение графа в виде матрицы смежности

**Функционал:**

- загрузка графа из файла (`loadGraphFromFile`)
- экспорт графа в .dot формат (`exportGraphToDot`)

---

`s21_graph_algorithms`

Библиотека алгоритмов на графах.

**Основной класс:**

`GraphAlgorithms`

**Реализованные алгоритмы:**

- DFS (обход в глубину, нерекурсивный)
- BFS (обход в ширину)
- Дейкстра (кратчайший путь между вершинами)
- Флойд–Уоршелл (все пары кратчайших путей)
- Прим (минимальное остовное дерево)
- Муравьиный алгоритм (задача коммивояжёра)

## Консольное приложение (CLI)

Реализовано меню для проверки функционала библиотеки:

Возможности:

- загрузка графа из файла
- DFS обход
- BFS обход
- поиск кратчайшего пути между вершинами
- матрица кратчайших путей
- минимальное остовное дерево
- решение задачи коммивояжёра

## Тестирование
- покрытие unit-тестами всех публичных методов
- тестируются: Graph, GraphAlgorithms, структуры данных (Stack, Queue)

## Сборка

Проект собирается через Makefile:

```bash
make all                  # очистка, сборка проекта, запуск тестов
make test                 # сборка и запуск тестов
make s21_graph            # сборка библиотеки s21_graph
make s21_graph_algorithms # сборка библиотеки s21_graph_algorithms
make app                  # сборка приложения
make run                  # запуск приложения
make clean                # очистка
```

## Быстрый запуск

```bash
make app
make run
```

## Требования к графу

Граф должен удовлетворять следующим условиям:
- веса ребер — натуральные числа
- допускаются петли
- веса могут различаться на всех ребрах
- граф связный
- матрица смежности динамического размера

## Особенности реализации

- строгая изоляция GraphAlgorithms от внутренней структуры Graph
- использование самописных Stack и Queue
- номера вершин начинаются с 0
- отказ от рекурсивного DFS (только итеративный)
